# Manufacturing Sales Analytics

An end-to-end data analytics portfolio project focused on sales performance, profitability, customer behavior, product performance, delivery performance, and payment analysis in a manufacturing company.

## 🎯 Project Objective

The objective of this project is to analyze manufacturing sales data and identify key drivers of revenue, profitability, customer performance, product performance, and operational efficiency.

## ❓ Business Questions

1. How are sales and profitability changing over time?
2. Which products generate the highest revenue and profit?
3. Which customers and industries are the most valuable?
4. Which regions perform best?
5. How do discounts affect profitability?
6. Which customers have poor payment behavior?
7. What factors are associated with delayed orders?

## 📊 Dataset

The project uses a synthetic manufacturing dataset containing:

- 500 customers
- 60 industrial products
- 4,000 orders
- 8,980 sales line records
- 6,537 payment records

Main entities:

- Customers
- Products
- Orders
- Sales Lines
- Payments

## 🔍 Current Stage

### Phase 1 — Data Understanding

Initial data exploration has been completed using Python and Pandas.

### Initial Findings

- Sales records: 8,980
- Total Net Sales: $486.8M
- Gross Profit: $140.1M
- Overall Gross Margin: 28.8%
- Missing DiscountPct values: 20
- Missing Customer City values: 8
